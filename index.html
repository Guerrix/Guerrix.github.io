About

Over the years, I've found that the hardest engineering problems rarely come down to writing code. They usually involve understanding existing systems, navigating constraints, choosing trade-offs, and getting reliable software into production.

My background is rooted in iOS and mobile architecture, across fintech, consumer products, healthcare and wellness platforms, startups, and consulting engagements. Increasingly, that work has expanded into the systems and decisions around mobile software, and more recently, how AI-assisted development changes, and doesn't change, that work.

I'm based in Hermosillo, Sonora, Mexico, and work with distributed teams remotely.

Selected Work

Engineering problems I've owned, and the judgment required to solve them.

01

Security · System Design · Cross-Functional Delivery

Security and account protection in a regulated fintech platform

In a regulated fintech environment, account protection is a systems problem, not a single feature. I owned the architecture and rollout of a KYC Refresh initiative, alongside security work spanning OTP/2FA, Secure Code, Trusted Contacts, and hardening driven by penetration-testing findings like jailbreak detection and Face ID vulnerabilities.

02

Release Engineering · Reliability · Technical Leadership

Owning mobile releases beyond "code complete"

Shipping mobile software is rarely finished when the implementation is. As iOS Release Manager during high-impact release cycles, I owned release readiness and production-issue mitigation across cross-functional teams, the judgment call being less "is it built?" and more "is it actually ready?"

03

Architecture · Performance · Media

Modernizing a media-heavy mobile platform

As Lead iOS Engineer on a high-engagement consumer video platform, the work meant evolving several layers of a production system at once, not one clean migration: contributing to an OpenGL-to-Metal rendering pipeline, a custom video caching module for playback reliability, and the CircleCI/Fastlane release pipeline underneath it all.
